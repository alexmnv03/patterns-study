# Фабричный метод

Это пример сложнй реализации паттерна

Стройка

Надо создать созадние роботов строителей

К нам приходит запрос на создание нужного типа робота-строителя метод builderGenerator.
И в ответе получаем конкретный тип фабрики для создания нужного строителя - метод только для демонстрации

BuilderRobot - общий тип роботов
Конкретные типы:
WelderBot - сварщик
MasonBot - каменщик
CraneBot - крановщик
CarpenterBot - плотник
PlastererBot - штукатур
PlumberBot - сантехник
HelperBot - подсобник

BuilderAbstractFactory - абстрактная фабрика
Конкретные фабрики
WelderBotFactory
MasonBotFactory
CraneBotFactory
CraneBotFactory
CraneBotFactory
PlastererBotFactory
Factory

Суть задачи:
1. Эти все строители строят дом
2. Чтобы построить дом за определенное время надо произвести например 100 000 единиц работы всем строителям
3. Каждый вносит в строителььство в единицу времении свой вклад, надо учесть это в методах и свойствах описания строителей
4. Но так как все строители работают одновременно, то каждый строитель вносит свой вклад оптималььно только при наличии оптимального
   количества других строителей, в противном случае у него будут простои и понадобится больше времени для постройки дома, это надо учесть в коде.
   Например одному каменщику надо 2 подсобника, иначе он будет простаивать, а если подсобников будет три, то простаивать будут уже они.
   Надо продумать и реализовать такую же схему и для других строителей.
5. Таким образом сначала мы должны создать список всех строителей, причем мы должны иметь воозможность создавать их в любом количестве,
   а потом запускается процесс стройки
6. Сам процесс создания строителй должен быть реализован с помощью фабричного метода, потом уже переделаем на абстрактную фабрику.
7. Программа должна запускать процесс постройки дома и подсчитывать сколько единиц работы делается каждый день и
   сколько дней понадобилось для постройки всего дома

Ключевая логика

Каждый робот имеет базовую производительность.
Но реальная эффективность (efficiency) зависит от количества нужных типов коллег:
Каменщик → требует 2 подсобников.
Плотник → 1 подсобник.
Штукатур → 0.5 подсобника.
Сантехник → 1 подсобник.
Крановщик → 1 сварщик.
Эффективность не превышает 100% (если помощников больше, лишние простаивают).
Все работают параллельно, и каждый день вносят вклад в общий прогресс.
